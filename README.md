# Воронеж Моторбокс

Демо сайта автосервиса в Воронеже. В форме используются тестовые данные. Она проверяет их в браузере без отправки на сервер.

## Что можно проверить

- Нажать «Выбрать ТО» и убедиться, что поле «Услуга» заполнилось.
- Нажать «Проверить заявку» на пустой форме. Ошибки появятся у обязательных полей.
- Ввести телефон `123`. Форма покажет подсказку о формате.
- Заполнить обязательные поля и ввести `+7 (000) 000-00-00`. Появится подтверждение проверки.
- Открыть страницу на телефоне. На узком экране карточки и поля формы выстраиваются в одну колонку.
